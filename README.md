# Hair Clinic Turkey

**Hair Transplant Turkey by Hair Clinic Turkey** — Premium hair restoration website built with Next.js 15, TypeScript, and TailwindCSS.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** TailwindCSS
- **Font:** System font stack (`font-sans`)

## Pages

| Route | Description |
|---|---|
| `/` | Home — hero, methods overview, gallery, pricing, reviews, lead form |
| `/hair-transplant-methods` | FUE, DHI & Sapphire FUE with comparison table |
| `/before-after` | Patient result gallery with BeforeAfterSlider |
| `/hair-transplant-turkey-cost` | Pricing packages, cost comparison table, FAQ |
| `/reviews` | Patient testimonials from 40+ countries |
| `/about` | Clinic story, surgeon profiles, certifications |
| `/contact` | Consultation form, WhatsApp, contact details |

## Components

- `Header` — sticky navigation with mobile hamburger menu
- `Footer` — links, contact info, certifications, disclaimer
- `WhatsAppButton` — floating bottom-right WhatsApp CTA
- `ConsultationForm` — lead capture form with success state
- `BeforeAfterSlider` — CSS side-by-side before/after comparison
- `TrustBadges` — ISO, JCI, Google rating, patient count badges

## Getting Started

```bash
npm install
npm run dev      # development
npm run build    # production build
npm start        # production server
```
